# Neurometric Status Page

Uptime monitor and status page for Neurometric AI infrastructure and web services, powered by [Upptime](https://upptime.js.org).

- **Status Page:** [status.neurometric.ai](https://status.neurometric.ai)
- **Monitored Services:**
  - Website (`www.neurometric.ai`)
  - API Gateway (`api.neurometric.ai`)
  - Wharf Model Gateway (`wharf.neurometric.ai`)
  - SLM Marketplace (`marketplace.neurometric.ai`)
  - TTC Leaderboard (`leaderboard.neurometric.ai`)
  - Task Explorer (`taskrouter.neurometric.ai`)
  - Inference Studio (`studio.neurometric.ai`)
